7.1 Continuous-Time Markov Chain Models：用跳跃描述离散生成

状态离散、时间连续，分别是什么意思？

“离散”描述的是状态：XtX_tXt​ 每次取值都是一条由词表 token 组成的序列。状态空间也包含不通顺的序列，数据分布才区分哪些更像真实语言。“连续时间”描述的是时间轴：ttt 可以是 0.2、0.201 或 0.20137，跳跃不必只发生在整数时刻。一条样本轨迹通常在一段时间内保持不变，到某一时刻突然改变，然后继续保持。

图 17 的横轴是连续时间，纵轴只有 S1,S2,S3S_1,S_2,S_3S1​,S2​,S3​ 三种状态。水平段表示这次样本没有跳跃，竖直变化表示状态切换；在跳跃时刻，实心点表示采用的新值，空心点标出离开的旧值。一条样本轨迹会突然跳跃，而许多样本形成的状态概率仍可以随时间平滑变化。后面 KFE 描述的是这些概率的变化，不是对图中阶梯轨迹逐点求普通导数。

Markov 性是说：给定当前完整状态后，预测下一状态不需要再知道更早的历史：

Pr⁡(Xt+h=y∣Xt=x,更早的状态)=Pr⁡(Xt+h=y∣Xt=x).\Pr(X_{t+h}=y\mid X_t=x,\text{更早的状态})=\Pr(X_{t+h}=y\mid X_t=x).Pr(Xt+h​=y∣Xt​=x,更早的状态)=Pr(Xt+h​=y∣Xt​=x).

这里的“当前状态”包含整条当前序列。因此网络可以读取当前句子的所有位置，利用上下文；Markov 性不要求只看一个词，也不要求忽略句子前后文。它限制的是对这条随机过程过去轨迹的依赖。

token 在网络内部仍然可以经过连续的 embedding 和 Transformer 计算。连续的特征计算与离散的生成状态并不冲突：网络输出概率或速率，采样后得到的状态仍是一条离散 token 序列。本章采用跳过程来描述状态演化；“离散扩散”这一名称不表示把布朗运动直接加到 token ID 上。

这一步把“训练一个生成过程”转成了“训练一组带上下文的分类预测”。连续 Flow Matching 中，平方误差使预测趋向条件平均速度；这里，交叉熵使预测趋向条件类别概率。两者都避免在每次训练更新中完整模拟生成轨迹。

读算法时可以分为四段：先抽 z、t；直接合成 x；用网络输出 d×Vd\times Vd×V 个 logits 并做 softmax；用 z 的逐位置标签计算交叉熵、反向传播。训练不需要先从噪声一步步跑到 t，再构造这个样本。每次随机抽一个 t，就能覆盖不同噪声程度。

Remark 40：为什么它和连续 Flow Matching 如此相似？

两类模型的共同结构是：先指定从噪声到数据的分布路径，再构造让随机过程沿该路径演化的局部规则，最后用容易获得的条件监督来学习这些规则。连续模型的局部规则可以是速度场，CTMC 的局部规则是速率矩阵。Generator Matching 将这类思路推广到更一般的 Markov 过程。

“Generator”在此指随机过程的无穷小生成算子：它描述任意状态函数的期望在极短时间内怎样变化。对 CTMC，给一个函数 f，它的生成算子可以写成：

Atf(x)=∑y≠xQt(y∣x)[f(y)−f(x)].\mathcal A_tf(x)=\sum_{y\ne x}Q_t(y\mid x)[f(y)-f(x)].At​f(x)=y=x∑​Qt​(y∣x)[f(y)−f(x)].

每项都是“跳跃速率 × 跳过去后 f 的变化”。对确定性连续流，对应局部变化则是 ut(x)⋅∇f(x)u_t(x)\cdot\nabla f(x)ut​(x)⋅∇f(x)。这些是不同状态空间中描述局部演化的工具；本章不需要先掌握统一框架，已经可以实现前面的训练与采样。
