卷积网络的主线只有四件事：局部连接规定谁能读谁，参数共享规定哪些边用同一权重，步幅与补零规定输出网格，池化汇总邻域响应。下面逐图回答这些规则的含义和边界。

1. 从矩阵乘法到卷积：算什么、怎样求梯度（第 2–7 页）

讲义第 2–3 页的“替换矩阵乘法”是指把无结构的稠密线性映射改成有结构的线性映射；损失函数、链式法则和梯度下降仍照常使用。输入可是一维序列、二维图像或三维时空网格，差别在核的维度。对二维输入，深度学习框架通常计算的是互相关，即核不翻转：

3. ReLU 与池化：哪一种“不变”（第 14–17 页）

左右做的事完全一样

数据流都是 卷积仿射变换 → ReLU → 池化。左边把三个阶段合称一个“卷积层”，右边逐个称“层”；只是术语颗粒度不同。狭义的 Conv2d 只计算核扫描与偏置；ReLU、池化可接可不接。ReLU⁡(z)=max⁡(0,z)\operatorname{ReLU}(z)=\max(0,z)ReLU(z)=max(0,z) 加入非线性；池化再汇总邻域。

位置移动一格，哪些值没变？

上排检测值约为 [0.1,1,0.2,0.1][0.1,1,0.2,0.1][0.1,1,0.2,0.1]，下排峰值移到第三格。宽 3、步幅 1 的窗口中，中间两个窗口依旧都含那个峰值，所以输出仍为 1；两端的结果变了。最大池化只提供局部位置容忍，不保证整张特征图平移后完全相同。此图步幅为 1，因此也没有下采样。

跨通道池化不是空间池化

多个检测器分别对同一目标的几种已学形态敏感。相同位置取 pi,j=max⁡cai,j,cp_{i,j}=\max_c a_{i,j,c}pi,j​=maxc​ai,j,c​：不管是检测器 1 还是 3 响应较强，池化单元都能较大。代价是丢失“哪一种形态”更强的信息；前提是训练确实学到了这些变形检测器。

池化与下采样何时同时发生

[0.1,1,0.2,0.1,0,0.1][0.1,1,0.2,0.1,0,0.1][0.1,1,0.2,0.1,0,0.1] 用宽 3、步幅 2 取最大值得 [1,0.2,0.1][1,0.2,0.1][1,0.2,0.1]。三个窗口分别覆盖位置 1–3、3–5、5–6。最后一个窗口只有两个元素，讲义允许保留；若采用“窗口必须完整”的 valid 约定，则只得到前两个输出。输出尺寸必须连同边界约定一起说。

区分两个词：步幅为 1 的卷积对平移近似等变：输入移动，响应也跟着移动（边界会破坏精确等变）。池化让某些小范围移动得到相同汇总值，是局部近似不变。若步幅大于 1，采样还会引入更多位置敏感性。

4. 分类头为什么有三种（第 18 页）

三列共享前半段：256×256×3 → 卷积/ReLU 得 256×256×64 → 步幅 4 池化得 64×64×64 → 卷积/ReLU 后仍为 64×64×64。后半段是三种选择：

  1. 左：池化到 16×16×64，展平为 16,384 维，接 1,000 类全连接。末层有 16 384×1 000+1 000=16 385 00016\,384\times1\,000+1\,000=16\,385\,00016384×1000+1000=16385000 个参数。
  2. 中：先池到 3×3×64，仅 576 维，末层为 576×1 000+1 000=577 000576\times1\,000+1\,000=577\,000576×1000+1000=577000 个参数。
  3. 右：卷积产生 1,000 张 16×16 类别响应图；各通道分别对空间 16×16 求平均，成为 1,000 个分数，再 softmax。卷积末层参数取决于核大小，讲义未指定。

软最大值把 1,000 个分数归一为类别概率；全局平均没有把 1,000 个类别混成一个数。

5. 步幅、补零与连接变体（第 19–23 页）

单轴输出长度：Nout=⌊N+2P−KS⌋+1N_{\rm out}=\left\lfloor\frac{N+2P-K}{S}\right\rfloor+1Nout​=⌊SN+2P−K​⌋+1这里先假设膨胀率为 1、两侧各补 PPP 个零，只保留完整卷积窗口。二维对高、宽各算一次。池化若允许末尾不完整窗口，要改用相应边界规则。

步幅 2 跳过的是输出位置

图中直接算 s1,s2,s3s_1,s_2,s_3s1​,s2​,s3​，等价于先算步幅 1 的 z1,…,z5z_1,\ldots,z_5z1​,…,z5​，再取 z1,z3,z5z_1,z_3,z_5z1​,z3​,z5​。x2,x4x_2,x_4x2​,x4​ 仍参与邻近窗口的计算，并没有从输入中删去。步幅使网格变稀疏，同时缩小特征图。

补多少个零？先决定目标尺寸

核宽 3、步幅 1，不补零每层减少 2：长度 5 → 3 → 1。若要保持 5，每侧补 P=(K−1)/2=1P=(K-1)/2=1P=(K−1)/2=1 个零。核宽 5 则每侧补 2 个。图里的黑点是每一层重新加入的固定零，不是上一层产生的可学习神经元。偶数核或非对称目标尺寸可能需要左右补不同数量。

两条独立的设计轴

按图中 5 入 5 出、局部核宽 2、忽略偏置计：局部无共享共 9 条边、9 个权重；标准卷积仍是这些局部边，但只用 2 个共享权重；全连接有 5×5＝25 个独立权重。局部与否决定连哪些边；共享与否决定边是否复用同一个数。

通道连接是另一回事

图中有 4 个输入通道和 4 个输出通道：前两个输出只连前两个输入，后两个输出只连后两个输入。每个通道对仍在空间网格上用局部核。若核为 3×3，全通道连接需 4×4×9=1444\times4\times9=1444×4×9=144 个权重；分两组则 2×(2×2×9)=722\times(2\times2\times9)=722×(2×2×9)=72。这是分组卷积思想；不同于图 9.9 的“跨通道取最大值”。

Tiled 是周期复用权重组

中排按位置交替使用 A=(a,b)A=(a,b)A=(a,b)、B=(c,d)B=(c,d)B=(c,d)，于是核组序列为 A,B,A,B,AA,B,A,B,AA,B,A,B,A。该图中局部无共享、tiled、普通卷积分别用 9、4、2 个权重（不计偏置）。它没有改变局部连接范围，也不是把图片切成互不重叠的块。

6. 迭代标注、学到的核、后续架构（第 24–27 页）

图中 U、V、W 怎样共享

同一张 XXX 在每轮经同一 UUU 提取信息；H(t)H^{(t)}H(t) 经同一 VVV 产生预测 Y^(t)\hat Y^{(t)}Y^(t)；上一轮的预测标签 Y^(t−1)\hat Y^{(t-1)}Y^(t−1) 经同一 WWW 回馈给下一轮隐藏层。可记作 H(t)=f(U∗X+W∗Y^(t−1))H^{(t)}=f(U*X+W*\hat Y^{(t-1)})H(t)=f(U∗X+W∗Y^(t−1))、Y^(t)=g(V∗H(t))\hat Y^{(t)}=g(V*H^{(t)})Y^(t)=g(V∗H(t))，首轮反馈设为零。U、V、W 是三套不同参数；各自跨迭代复用。这里 ttt 是细化轮次，不是视频帧序号。

为什么像一组小条纹

Gabor 核可理解为“高斯包络 × 余弦条纹”：g(x,y)=exp⁡[−(x′2+γ2y′2)/(2σ2)]cos⁡(2πx′/λ+ϕ)g(x,y)=\exp[-(x'^2+\gamma^2y'^2)/(2\sigma^2)]\cos(2\pi x'/\lambda+\phi)g(x,y)=exp[−(x′2+γ2y′2)/(2σ2)]cos(2πx′/λ+ϕ)，其中 x′=xcos⁡θ+ysin⁡θx'=x\cos\theta+y\sin\thetax′=xcosθ+ysinθ、y′=−xsin⁡θ+ycos⁡θy'=-x\sin\theta+y\cos\thetay′=−xsinθ+ycosθ。θ\thetaθ 控制方向、σ\sigmaσ 控制范围、λ\lambdaλ 控制频率、ϕ\phiϕ 控制相位。图中三组分别展示位置/旋转、尺度、频率/相位变化；亮暗代表正负权重，灰色接近零。

“像 Gabor”不等于预设 Gabor

训练后的许多局部权重呈现有方向的明暗条纹，也有颜色对立图案。左图来自无监督 spike-and-slab sparse coding 学到的图块权重；右图才是有监督 convolutional maxout network 第一层的卷积核。两组来源不同，它们也并非个个都是严格的 Gabor 函数；图中显示的是权重，不是某张图片的激活值。

末页四种架构：分别解决什么

讲义名称抓住一个设计点
Spatial Transducer Net各层保持卷积形式，从输入网格产生对应的空间输出网格；讲义所用名称不要混同为 Spatial Transformer Network。
All Convolutional Net用跨步卷积缩小网格，减少对独立池化层的依赖。
Inception并行的不同尺度分支提取特征，常用 1×1 卷积控制通道数与计算量。
ResNet残差块 y=x+F(x)y=x+F(x)y=x+F(x) 提供恒等捷径，使很深网络更容易优化；它不保证任何设置下梯度都绝不消失。

7. 最小代码：手算与自动求导对照

下面直接复现图 9.1 的 2×2 例子。PyTorch 的 F.conv2d 按 [批量, 输入通道, 高, 宽] 读取输入，核按 [输出通道, 输入通道/组数, 核高, 核宽] 存放。

import torch
import torch.nn.functional as F

x = torch.arange(1., 13.).reshape(1, 1, 3, 4).requires_grad_()
k = torch.tensor([[[[1., 2.], [3., 4.]]]], requires_grad=True)
y = F.conv2d(x, k)                 # stride=1, padding=0
print(y.shape, y[0, 0])            # (1, 1, 2, 3); [[44,54,64],[84,94,104]]
y.sum().backward()
print(k.grad[0, 0, 0, 0])          # 24
print(k.grad[0, 0, 1, 1])          # 54
print(x.grad[0, 0, 1, 1])          # 10

想继续验证尺寸，可分别修改 stride 和 padding，再用上面的输出长度公式预先算出形状；groups=2 对应分组通道连接，但输入、输出通道数都要能被 2 整除。
